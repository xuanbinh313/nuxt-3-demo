# Nuxt Minimal Starter

## Requirement
- Layout
- sample CRUD backend
- FE interact by server side and client side
- search with params
- asset
- Error page handle

## Setup

Make sure to install dependencies:

```bash
# yarn
yarn install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# yarn
yarn dev
```

## Production

Build the application for production:

```bash
# yarn
yarn build
```

Locally preview production build:

```bash
# yarn
yarn preview
```
